<p>A Burp Suite extension for CORS testing and browser verification. Probes Origin rules, validates preflight behavior, and exports pages for checking actual cross-origin read access.</p>
<p><code>Burp Suite</code> <code>Java</code> <code>CORS</code></p>

<p>A Burp Suite extension based on <a href="https://github.com/kapytein/jsonp">kapytein/jsonp</a>. Uses randomized callbacks to probe JSONP behavior and support manual assessment of cross-origin data exposure.</p>
