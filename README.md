### ✨ Selected Projects

#### 🧠 [CTF Wiki](https://github.com/doudou0308/ctf-wiki)

**A CTF knowledge base for LLM agents.** Connects problem-solving approaches with reference material through structured pages, retrieval keywords, and cross-references. Can also be browsed in Obsidian.

`LLM Agents` · `Knowledge Base` · `CTF` · `Obsidian`

#### 🐳 [Agent Docker Tools](https://github.com/doudou0308/agent-docker-tools)

**A reusable Docker environment for CTF tools.** Integrates security analysis tools and GhidraMCP, working with agents and CTF Wiki to connect planning, knowledge retrieval, and tool execution.

`Docker` · `Python` · `MCP` · `CTF Tooling`

#### 🔎 [JSONP Hunter](https://github.com/doudou0308/Jsonp_Hunter)

**A Burp Suite extension based on kapytein/jsonp.** Probes JSONP behavior with randomized callbacks to help manually assess potential cross-origin data exposure.

`Burp Suite` · `Jython` · `Web Security` · `JSONP`

#### 🛡️ [CORS Hunter](https://github.com/doudou0308/CORS-Hunter)

**A Burp Suite extension for CORS testing and browser verification.** Supports Origin rule probing, preflight validation, and verification page export to distinguish policy signals in responses from actual cross-origin read access.

`Burp Suite` · `Java` · `CORS` · `Web Security`

#### ⚡ [MultiLang OJ](https://github.com/doudou0308/MultiLang-OJ-LLM)

**A multilingual online judge built with Spring Boot and Vue 3.** Supports compiling and running Java and C, connecting backend services, problem data, and an online code editor.

`Java` · `Spring Boot` · `Vue 3` · `TypeScript` · `MySQL`
